## About the Project

**TUMPENG (Tata Ukur Mutu Prestasi dan Evaluasi Nilai Pegawai)** merupakan proyek pengembangan sistem informasi berbasis web untuk mendukung proses monitoring, pengelolaan data, dan penilaian kinerja pegawai di **Badan Pusat Statistik (BPS) Kota Bogor**.

Proyek ini dikembangkan sebagai bagian dari kegiatan akademik Program Studi Sistem Informasi, Universitas Bina Sarana Informatika (UBSI). Pengembangan dilakukan dengan mengacu pada analisis sistem existing ASINAN BOGOR sebagai dasar dalam memahami proses bisnis dan kebutuhan pengguna.

TUMPENG dirancang untuk membantu pengelolaan informasi kinerja pegawai secara lebih terstruktur, memudahkan pemantauan data, serta mendukung proses evaluasi kinerja.

## Project Objectives

* Mengembangkan sistem informasi monitoring dan penilaian kinerja pegawai berbasis web.
* Mendukung pengelolaan data kehadiran dan evaluasi kinerja pegawai.
* Mempermudah pemantauan informasi kinerja sesuai hak akses pengguna.
* Meningkatkan keteraturan pengelolaan data dan dokumen pendukung evaluasi.
* Menerapkan hasil analisis sistem informasi ke dalam pengembangan aplikasi.

## Main Features

| Module         | Description                                                 |
| -------------- | ----------------------------------------------------------- |
| Dashboard      | Menampilkan ringkasan informasi kinerja dan monitoring.     |
| Kehadiran      | Mengelola dan memantau data kehadiran pegawai.              |
| Penilaian SKP  | Mendukung pengelolaan dan evaluasi penilaian SKP.           |
| Pelaporan      | Mengelola dokumen dan laporan kinerja pegawai.              |
| Penetapan SKP  | Mendukung pengelolaan dokumen penetapan SKP.                |
| Evaluasi SKP   | Mendukung pengelolaan dokumen evaluasi berdasarkan periode. |
| Manajemen User | Mendukung pengelolaan pengguna dan hak akses sistem.        |
| Help Desk      | Menyediakan panduan penggunaan dan FAQ sistem.              |

*Catatan: Daftar fitur menggambarkan ruang lingkup pengembangan yang direncanakan; implementasi aktual bergantung pada versi aplikasi.*

## User Roles

| Role       | Access                                                                  |
| ---------- | ----------------------------------------------------------------------- |
| Kepala BPS | Melihat informasi dan hasil monitoring.                                 |
| Admin      | Mengelola data dan fitur sistem sesuai kewenangan.                      |
| Operator   | Melakukan input data sesuai tugasnya.                                   |
| Panitia    | Melakukan input pada bagian yang menjadi kewenangannya.                 |
| Pegawai    | Melihat informasi kehadiran dan mengisi survei penilaian yang tersedia. |
